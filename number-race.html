📘 Game Rules

🎯 Goal: be the first player to make exactly the target (10, 100, or 1000).
🎲 Dice: only the dice that match your target are shown.
⚠️ Exact finish: if a roll would push you past the target, the move is rejected — but the turn still passes to the next player. So think before you roll!
📊 Stats: you can see each player's total, rolls, moves, and wins in the player list.
👀 Board: each place shows its digit and exactly 9 circles. Ones circles say 1, tens say 10, hundreds say 100.
🔄 Carry: when a place reaches 10, it resets to 0 and 1 moves to the next place.
🎮 Modes: Shared Board = everyone adds to one board. Individual Boards = only the active player's board is shown; press “Pass to …” to hand over.
🏆 Wins: the winner of each round gets a trophy. Press New Round to keep playing — the wins stay on the scoreboard.
🔊 Sound: tap the speaker button (top-right) to mute or unmute sounds and voice.

🔄 How the Carry Function Works

1. A place can show 0 to 9 circles.
2. Add one more. 9 + 1 = 10.
3. Write 0 in the current place and carry 1 to the next place.
Example: 129 + 1 = 130. Ones 9 → 0, while one new ten is carried.
{ Pascal-style place-value logic } Ones := N mod 10; Tens := (N div 10) mod 10; Hundreds := (N div 100) mod 10;
mod gives the remainder. div gives the whole-number part. Together they split a number into its place-value digits.
